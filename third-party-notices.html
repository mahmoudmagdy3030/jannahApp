Device and calculation services

  • Apple iOS services: location, motion/orientation, speech recognition, and local notifications.
  • Capacitor: native application runtime and plugins.
  • Adhan: local prayer-time calculations.

Location, market, and version data

  • BigDataCloud: reverse geocoding.
  • OpenStreetMap Nominatim: manual city lookup.
  • Gold API: reference gold price.
  • ExchangeRate-API: reference currency conversion.
  • GitHub: public version metadata on Android/web builds.

Quran, audio, imagery, and video

  • AlQuran Cloud: Quran text, translations, and Tafsir responses.
  • EveryAyah: externally hosted recitation audio.
  • MP3Quran: externally hosted recitation audio.
  • Quran.com: externally hosted Mushaf page assets.
  • IslamCan: externally hosted Adhan audio fallbacks.
  • YouTube: externally hosted Tafsir and educational videos.
  • Unsplash: selected externally hosted imagery.
  • Google Fonts: web fonts used by the interface.
